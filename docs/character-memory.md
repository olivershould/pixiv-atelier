# 本机角色记忆

日常优先使用标题上方的历史角色选择，一次填写当前账号的完整投稿格式，见 [历史投稿模板](posting-templates.md)。需要记录新的视觉参考或更正记忆时，展开「调整标签与角色记忆」，点击「记住此角色」。名字会从当前标题带入，也可填写或更正；所属游戏和角色标签均以独立标签显示，每类可选填最多 4 个。输入后按回车或点击「添加」，点击标签上的 × 可移除；也可粘贴用逗号、顿号或换行分隔的多个标签，标签内部空格保留。重复标签自动合并。已有记忆的多标签会逐个显示，无需重新填写。

勾选「我确认图中只有这一个角色」并点击「确认并记住」后保存。未按回车的标签会在保存时一并加入；超出数量或长度限制时保留输入并提示修改。修改标签后需要重新勾选确认。只有这个明确操作会保存角色标注，普通标题编辑或保存草稿不会自动学习。

手动填写标题中的角色名，或记忆表单中的英文名，停顿约 0.7 秒或离开输入框后会自动匹配。存在当前账号的历史模板时，优先使用其完整写法与顺序；否则使用明确保存的角色记忆及此账号已核实的 Pixiv 标签，需要时才向 Pixiv 精确检索。无模板的补名仍按游戏 → 角色置前，保留分级与其余画面标签，最多 10 个。记忆表单里尚未手动修改的标签栏也会补齐，仍须勾选确认并点击保存才学习图片。

此操作依据你提供的名字，不把它包装成模型识图结果。现有标签缓存能直接解析的角色无需重连 Chrome。同名跨游戏、历史记录冲突或找不到明确对应时，不自动猜一个角色；请填写更明确的角色标签，或在记忆表单中补全游戏和角色标签。多图及已经检测为多人时不触发单角色补名。

同一文件再次上传，即使换文件名或换投稿账号，也会复用你确认的名称。不同图片会比较本机参考图片，显示「可能是…」候选；确认候选后，该图片成为此角色的新参考。不同姿势、服装和画风可能导致找不到候选；视觉相似也可能来自相近服饰或构图，因此不把相似度视作身份准确率，也不凭相似度自动填写标题。此功能没有重新训练或修改原模型。

精确记忆可以纠正模型身份，但不会复制旧图片的分级、服装或画面标签。记住的游戏和角色标签仍需通过 Pixiv 实际匹配，再依当前账号的常用及历史写法排序；浏览器未连接时可能无法补齐这些标签。多图及检测到多个角色的图片仍不自动填入单角色标题，也不能作为单角色记忆保存。

同一工作空间的账号共用角色记忆；演示和真实空间完全分开。英文名相同而游戏标签不同的角色分别保存。选择「更正角色」只纠正当前图片的归属；旧角色的其他参考保留。在「设置 → 角色记忆 → 管理记忆」可以删除整个角色的记忆，上传图片和已保存作品不会被删除。当前限制为每个空间 200 个角色、每个角色 20 张参考。

图片和记忆仅保存在本机。记忆文件为 `.data/character-memory.json`，记录参考图片 SHA-256、英文名、标签和当前固定模型提取的 1024 维特征。特征随一次正常识图提取，不额外下载模型，不发给浏览器页面。新图只比较相同模型版本的特征；原图的精确摘要匹配不受模型特征变更影响。

保存时核对服务端已分析图片的摘要和账号、工作空间，拒绝过期或换图后的识图结果。识图记录在内存保留最多 30 分钟，重启应用或超时后，需要点「分析作品」再记忆。完整备份请按 README 备份整个 `.data`；「导出记录」不是角色记忆备份。
