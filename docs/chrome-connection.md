# Chrome 登录、预约与发布核实

内置连接通过本机 Google Chrome 访问 Pixiv，按实际 Pixiv 用户 ID 验证身份，不按 Google 账号名、窗口标题或当前浏览的作者推断登录者。浏览器登录、验证码及其他账号验证由用户完成。

## 专用 Chrome（推荐）

每个本地账号使用独立 Chrome 资料，和日常浏览器分开。首次登录后可保留状态供后台采集与预约使用。

1. 在真实工作空间的账号管理中填写对应 Pixiv 用户 ID。
2. 点击「使用专用 Chrome」；已经启用的账号点击「打开登录窗口」。
3. 在专用窗口登录该账号，回到画序点击「确认已登录」。
4. 应用核对原 Pixiv ID，成功后点击「转到后台」。
5. 按需使用「更新数据」「同步 Pixiv 状态」或「开始预约」。

“转到后台”再次核验身份，只关闭应用自己启动的该账号专用窗口，随后以无可见窗口的 Chrome 运行。日常 Chrome 窗口、Google 账号和原有标签页不受影响；日常后台操作不再请求日常 Chrome 的远程调试授权。

错号、登录失效或核实失败时保持待登录，不开启投稿，原账号资料、历史、默认时刻和队列保留。迁移前已经开启的投稿只在原账号身份和会员状态核验成功后恢复；原先关闭的不会自动开启。打开登录、确认身份、转后台本身不触发投稿或统计采集，已启用的后台定时任务仍按原规则执行。

账号卡的“上次运行方式”是最近已知状态，不保证实时在线。登录过期或需要验证码时，重新打开该账号登录窗口处理，再确认并转后台即可。

## 连接现有 Chrome（兼容）

1. 在需要的 Chrome 资料中登录 Pixiv，保留对应标签页。
2. 打开 `chrome://inspect/#remote-debugging`，启用远程调试。
3. 在账号管理显式选择「连接现有 Chrome」，允许 Chrome 的连接提示。
4. 选择检测到的 Pixiv 账号。绑定后默认仅连接和同步，投稿需另行开启。

这种方式复用现有登录，连接保持时复用会话；Chrome 重启、拒绝连接或会话变化后可能再次需要允许。程序不自动批准浏览器授权。默认读取 Windows Chrome 的本机调试端点，非标准资料目录可使用私有 `.data/browser-config.json` 的 `userDataDir`；终端启动也可使用 `PIXIV_CHROME_USER_DATA_DIR`。后台启动器会清理该环境变量。

绑定依赖所选 Pixiv 标签页；关闭或换号后需要重新绑定，不会自动改用另一个账号。读取与投稿不主动激活窗口，连接失败也不会通过抢前台恢复。专用模式则由应用维护独立资料，不依赖日常标签页。

## 预约与并行准备

「开始预约」只执行一轮已入队作品的同步与补位，不改变持续投稿开关，不恢复暂停队列。需要持续自动提交时，在账号管理开启投稿；自动检查每 6 小时一次，排期和检查时间保存在本机。

内置浏览器最多同时使用 2 个独立后台投稿页准备表单、上传图片。同一 Pixiv 账号的最终点击和远端确认依次执行，不同账号可同时提交。名额、身份和时间在提交前再次核对，外部投稿占满名额时仍保留待补位。

只有明确确认预约成功后，才关闭应用为本次投稿新建的页面。失败、超时或结果不明时保留页面供核对；用户原有页面不关闭。在无可见窗口的专用模式中，后台页面不会因此出现在桌面。

外部 HTTP 连接器没有内置独立页面与提交锁的保证，继续按单件流程执行。暂停会阻止尚未提交的后续作品，已发送的请求仍需核实，不能以打断响应假装未提交。

## 发布确认与只读自动核实

预约到点或从列表消失，不足以证明已经发布。提交前保存已发布作品基线；后续核对作者、标题、图片数量、作品类型、时间及可用的标签、分级证据。只有唯一匹配并且没有冲突时才关联最终作品 ID，更新为已发布。

基线缺失、信息不完整、候选过多、读取失败、标签或分级不一致，以及结果不唯一时，保留待核实，不猜测成功，也不重新上传。作品详情显示具体原因和最近核实时间；升级前缺少可靠基线的记录可能仍需人工提供实际作品链接。

已提交作品的只读核实每 6 小时独立检查，不要求开启投稿，暂停队列也不会阻止核实。工作台「同步 Pixiv 状态」可立即执行：它只核对登录、会员、完整预约列表和可确认的作品结果，不上传作品、不执行补位。一处账号失败会保留其原因，其他专用账号仍可独立核对。

确认发布只更新本地记录；真正补位需下一轮已授权的预约执行。使用「开始预约」时，该轮可以先确认发布再为待补位作品提交预约。不能把只读同步等同于开始预约。

必要时在作品详情使用现有「核对远端结果」，选择确认过的预约或填写作品链接。若在 Pixiv 手动改期，可对已关联的同一预约勾选采用远端排期；此操作更新本地时间，不重新上传。尚未提交且已过期的排期需要人工改期，不会自动变成立即发布。

## 数据与运行条件

专用登录资料保存在私有 `.data/chrome-profiles/`，提交记录保存在 `.data/browser-ledger.json`。它们可能包含登录状态、作品和账号信息，应随完整数据备份，不能公开上传。应用不要求在表单中填写 Pixiv 密码或复制 Cookie。

请保持本地服务运行、电脑在线及账号登录。关闭网页不停止后台服务；休眠、关机或服务退出时不会检查。统计采集、只读核实与自动投稿是不同任务，前两者不会自行开启投稿。

支持字段和未实现的远端操作见 [投稿字段与支持范围](pixiv-fields.md)，数据采样规则见 [数据统计](analytics.md)，启动与安全停止见 [独立运行说明](standalone.md)。
