# 投稿字段与支持范围

本文说明应用的本地表单和内置 Chrome 连接支持范围，不是 Pixiv 官方 API 规范。Pixiv 可能调整页面、权限或限制；提交时以实际账号、表单回读与远端响应为准。

## 基础字段

| 字段 | 本地规则与行为 |
| --- | --- |
| 作品类型 | 支持插画、漫画；小说、动图未实现 |
| 图片 | PNG、JPEG、静态 GIF；每件最多 200 张、总计 200 MiB、每张最多 32 MiB；可调整顺序 |
| 标题与说明 | 标题最多 32 字，说明最多 3000 字 |
| 标签 | 1–10 个；入队前需要确认；标签建议可以手动修改 |
| AI 作品 | 默认开启，使用专用字段提交；用户需确认实际创作方式 |
| 年龄限制 | 全年龄、R-18、R-18G；与同名标签分开保存 |
| 全年龄性描写 | 必须明确选择有或无 |
| 成人内容属性 | 默认留空，不能凭模型或历史作品自动勾选 |
| 原创声明 | 独立设置，不通过角色名、AI 标记或标签推断 |
| 公开范围 | 全体公开、仅登录用户、仅好友、非公开 |
| 互动权限 | 标签编辑、评论、加入珍藏册分别保存 |
| 预约时间 | 日期与时间分开，固定 JST，显示对应北京时间 |

填写后回读账号身份、字段、标签、预览图片数量和预约时间，不一致则停止。内置浏览器流程目前会在上传前拦截不支持的高级设置，包括带空格标签、漫画系列、自定义缩略图、图片回应、创作工具、成人内容属性和问卷等，避免静默忽略选项。比赛活动、创作工具、图片回应和问卷没有作为常规投稿输入开放。

已提交远端的作品详情只读，应用未实现远端修改、取消或替换图片。需要时请直接在 Pixiv 操作，再回到应用核对状态。

## 预约队列

应用按 Premium 权益、每账号同时最多 10 件预约、未来一周以及 30 分钟粒度检查预约条件。这个上限是同时占用的远端名额，不是每天最多投稿数量。所有来源的预约都纳入容量计算，包括直接在 Pixiv 建立的预约。

本地队列可保存更多作品及更远的时间，进入可预约窗口并有名额后才实际提交。提交前重新检查当前时间和账号；过期作品保留待处理，不会改成立即发布。

预约到点或从远端列表消失，不足以证明发布成功。应用需匹配实际发布作品，只有得到明确结果才释放本地占用并继续补位。网络超时、登录失效、验证码、权益变化或未知提交结果都会保留原因。仅确定未上传的失败可以重新预约；未知结果先核对远端，避免重复作品。

## 标签与识别

图像模型提供候选概念，静态词表仅提供搜索映射。标签是否已核实取决于账号历史、缓存或 Pixiv 实际查询。历史模板复用的是标签格式，不能证明新图身份或无条件复制旧图的服装、动作、分级。

模型建议、手动修改、角色记忆与历史模板均保留在本机。标签最终需要用户检查确认；投稿选项和声明应与作品实际内容一致。
