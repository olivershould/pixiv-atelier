# 历史投稿模板与一次选角色

上传单张、单角色图片后，在「选择角色」中搜索中文或英文名并点击角色。应用同时填写英文标题、该账号使用的游戏标签组合、角色标签和惯用搭配，保留历史字面与顺序。识图可靠认出已有历史角色时，自动使用相同流程。切换投稿账号时重新选择该账号的格式；不会把另一账号的游戏标签写法混进来。同名且无法唯一对应时仍需选择。

最终标签直接显示在作品信息页，可以删除或补充。历史中出现过但当前图片缺少证据的画面标签显示为可点击选项。常用标签池、完整识图候选、全站搜索及角色记忆位于「调整标签与角色记忆」，日常投稿无需展开。角色选择不等于保存图片记忆；首次未知角色仍可使用原来的标题匹配或显式角色记忆。

角色目录同时包含历史作品、共享角色记忆与已核实标签中的身份，不再只列最近投稿过的角色。默认显示前 8 项，可「展开全部」，中英文搜索遍历完整目录；保存角色记忆后会刷新列表。RuanMei、Ruan Mei、阮梅均可匹配同一角色，Sparxie 与 Sparkle 单独列出。

没有该角色专属历史时，使用当前账号同游戏作品的标签格式，只替换角色部分。角色记忆提供身份，不把保存记忆时的另一账号游戏写法带进来。当前模式下其他已绑定账号核实过的角色标签可以作为全站词汇补充，但不共享其游戏组合、排序或画面判断。手动加入常用池的普通文字不构成核实证据。此类选项标为「沿用本账号格式」，角色历史件数为零；格式参考作品单独记录。缺少当前账号历史时，回退到当前账号已核实游戏标签或明确保存的角色记忆，并如实标明来源。条件标签仍须当前图片证据支持才加入。

模板按工作空间、本地账号和 Pixiv 账号共同隔离，来自已核实的已发布作品。每次同步按作品 ID 合并历史，保留最新的最多 5,000 篇；「从 Pixiv 同步」仍为最多最近 60 篇的轻量同步。完整作品索引支持分批读取，每次最多 2,000 篇，可按返回位置续读；会核对当前登录账号、作品作者及作品状态，保留每件作品的标签原文与顺序。超时、限流和部分失败不清空已核实历史，并返回实际读取进度。没有重新同步时会使用已经保存的历史，不把旧缓存冒充新读取。以后经账号身份核实、发布成功且标签已确认的本地投稿也会补入历史；草稿、排队、预约中和失败作品不参与学习。

同一角色多篇投稿保留不同标签组合，按当前画面证据选择合适组合。游戏和角色标签直接复用原写法；少数通用惯用标签只有在至少 3 篇作品、占该账号历史至少 60% 时才作为可编辑默认项。衣服、动作等条件标签依据当前图片的高置信预测或用户明确选择决定，年龄限制始终使用当前图片/用户选择，不能从旧作品复制。自动识别、一次选角色和分级变更使用同一套规则。

标签模板在本机由 `.data/tag-pools.json` 和已确认发布记录生成。草稿的 `tagTemplate` 保存自动标签归属，重开草稿后换角色、换账号可清理旧模板标签并保留手动添加的标签。模板记录不会提交给 Pixiv。角色视觉记忆由同一工作空间的账号共用，详情见 [角色记忆](character-memory.md)。
